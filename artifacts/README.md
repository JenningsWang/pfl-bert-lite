# Artifacts Folder

Write real experiment outputs here after running on your training machine.

Suggested files:

- `metrics.jsonl`: round-by-round training and validation metrics
- `validation.log`: final validation log line and checkpoint path
- `profiler.txt`: profiler excerpt you can quote in applications
- `predictions.jsonl`: examples for error analysis
- `demo_round.json`: generated by `scripts/train_demo.py`
